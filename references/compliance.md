# 内容合规（小红书 / 抖音 镜像规则）

> 生成标题、正文、配图文案时审查。xhs 与 dy 规则**镜像**：xhs 禁提抖音，dy 禁提小红书。

## 严禁（限流/处罚）
### 1. 平台/竞品
- xhs：不提 抖音、橙色软件、B站/快手/微信。
- dy：不提 小红书，图卡不带别家水印。
### 2. 极限用语
第一、唯一、首个、NO1、Top1；最高、最低、最好、最大、最强、最全、最新、最佳；顶级、世界级、国家级、绝对、100%、永久。
### 3. 诱导互动
点赞、收藏、关注、转发三连、一键三连、口令、恭喜获奖、点击获取。
（引导讨论如"评论区聊聊"在 xhs 允许，但本号按纯信息做，已去掉——见 publishing.md。
### 4. 迷信 / 资质 / 隐私
塔罗占卜星座预测；医疗/金融/教育无资质；未经授权真人正脸、车牌、身份证。

## 本号额外
- **不要 `**`**（Markdown 加粗在小红书原样显示）。
- **标题/正文不写「评论聊/投票」**（纯信息）。
- 不要 AI 球星正脸、假队徽、模型手写大段中文。
- 图卡不写比分/数据（易错）。

## 战术分析 line 的踩坑点（做过就记着）
- **数据先核验**：发前 `web_search` 对照——比分、**进球者+分钟**、射门/射正/xG/控球、关键事件（失点/中柱/被吹/被挡）。多来源 + 引用。
- **进球者/译名别写错**：马尔基尼奥斯（不是克瓦拉茨赫利亚）、伊劳拉（不是伊拉奥拉）、居莱尔（不是居勒尔）、阿克利乌什、安东尼不在皇马（是"对阵皇马"非"旧主"）。拿不准先搜 `xhs topics` / `web_search`。
- **拿不到逐球坐标/分钟** → 图表标「**坐标示意/分钟示意/点量为准**」，别当真实数据误导。
- **图表不拉伸**：`preserveAspectRatio="xMidYMid meet"` + `chartbox{flex:1}`（自然大小居中、底栏到底）；别用 `none` 拉变形。
- **事件挤**（时间轴末段两事件）→ **分栏/换行**，别堆一行重叠。
- **值为 0 的柱/单位**：别画成 5px 小棒（难看）；0 就显示数字/空环，不用最小棒。
- **赢家主色一图一套**：谁赢用谁主色，对手灰/浅色；不混搭。
- **封面**：实拍 + 比分完整（谁是谁清楚）+ 联赛·轮次·日期；文字语义换行，不断词。
