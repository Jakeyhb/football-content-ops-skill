# 固定 IP 角色系统（小夜鹰观察员）

> 参考 `heytea-style` 的「先锁固定 IP，再进不同场景」。人物恒定、画风可变 → 主页不散。

## 一句话
先锁定一个固定的小 IP（足球观察员·夜鹰），再让 TA 进入不同文章场景（数据卡/手绘/3D/赛博）——**风格变、人不变**。

## 为什么能解决「主页乱」
- 每篇换风格（手绘→3D→赛博）像好几个人在运营。
- 只要**角色身份固定**，画风变化只是渲染方式不同，主页读起来就统一。

## 固定 IP 定义（锁死）
| 项 | 规则 |
|----|------|
| 角色 | 夜鹰观察员（夜场看球 × 数据/战术） |
| 形象 | 一只穿连帽衫/抱足球的猫头鹰：大而专注的眼（不是萌豆眼）、尖耳羽簇、短喙、两翅（当手）、两爪 |
| 特征锁 | 1–3 标志色（夜蓝/电蓝/暖橙）、1–2 材质线索、**≥1 非颜色结构记忆**（尖耳簇改变外轮廓） |
| 脸 | 双眼 + 短喙；120–140px 可读 |
| 四肢 | 两翅当手 + 两爪 |
| 风格 | 大胆硬朗 hand-drawn（黑线 + 账号色），不做可爱贴纸 |
| 色 | 角色用账号固定色；**场景/球队用主题色** |

## 进不同场景（渲染方式可变）
同一只夜鹰，只在"做的事"上变：
- 抱球 / 哨子 / 球场 / 战术板 / 奖杯 / 数据(xG热图) / 庆祝 / 深夜看球(心理×足球)。

对应 SVG 变体可从 `assets/ip/night-owl.svg` 改道具/姿态生成；透明 PNG `night-owl-transparent.png` 直接当角标。

## 出图前
- 先有 **identity reference（控制图）**，照同一张脸/轮廓渲染，确保一致性。
- 各篇照旧走 `football-data` 卡风 + 按队换色；只是**固定加这个 IP 小人**。

## 不要
- 每篇换不同风格/不同脸的「人物」。
- 用 AI 画真实球星正脸、队徽当 IP。
- 改掉特征锁 / 表情 / 四肢系统。
