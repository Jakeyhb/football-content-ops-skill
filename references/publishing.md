# 发布规范（小红书 / 抖音 / FlowUs）

## 小红书
```bash
xhs post \
  --title "$(cat title.md)" \
  --body  "$(cat body.md)" \
  --images 图集-1.png --images 图集-2.png --images 图集-3.png --images 图集-4.png \
  --topic 话题1 --topic 话题2 --topic 话题3   # ≤10 个
```
规则：
- `--images` **每个文件一个参数**（重复 `--images`）。
- `--topic` 最多 **10**；发布前 `xhs topics "词"` 核对存在（顺带定标准译名：伊纳西奥/居莱尔…）。
- **`--body` 不要 Markdown `**`**；不要评论/选项。
- 发布后**不要自评**（用户偏好"不用评论"）。
- 发布后追数据：点赞/收藏/评论/观看（FlowUs）。

## 抖音
- **默认手动发**（创作者中心/app），自动脚本 `scripts/douyin-post.py` 备用（之前自动化效果一般 + 会触发短信验证）。
- 图卡同套（大字号信息卡，1080×1440，≤35 张）。
- 标题 ≤30，简介精简（几行 + #话题），不要评论/选项。
- 手动发完 → 用 `scripts/dy-flowus-create.sh` 记 FlowUs（状态=已发布，填链接/ID/数据）。

## FlowUs 库
- 小红书：`scripts/xhs-flowus-create.sh "标题" "分类" "标签1,标签2" "状态"` → 库ID `060f200e-f17e-48cb-a677-fc26efb07807`。
- 抖音：`scripts/dy-flowus-create.sh "标题" "形态" "分类" "标签" "配乐" "话题" "状态"` → 库ID `df0459bc-350a-437f-aaa2-9f9c69ea6446`。
- 字段：标题/形态(图文/视频/其他)/分类/标签/配乐(无/热门/关键词/定制)/话题/状态(待发布/审核中/已发布/已删除)/链接/数据。

## 事实核验（发前必做）
- `web_search` 对照：比分、球员、时间、场馆、转会/租借（含买断与否）、教练。
- 引用来源（便于回查）。
- 译名标准：伊纳西奥(Inácio)、居莱尔(Güler)、恩佐等，用 `xhs topics` 确认。

## 发布前检查清单
- [ ] 标题 ≤20（xhs）/ ≤30（dy），标准译名
- [ ] 正文无 `**`、无评论/选项、话题 ≤10 且存在
- [ ] 图卡 1080×1440、大字号、**无比分数据**、标题不断词
- [ ] 按队换色、小夜鹰角标、封面用实拍/球场海报（无 VS）
- [ ] 事实已核对 + 来源
- [ ] 合规（见 `compliance.md`）
