# 战术分析（数据复盘）note-type

> 与「比赛前瞻」互补的第二条线：前瞻讲"赛前看什么"，战术讲"这场怎么打出来 / 数据怎么判"。视觉、结构、数据规则如下。

## 结构（4 页）
1. **封面**：实拍球员/球场海报 + 大字 **比分（完整，谁是谁清楚）** + 一句话定调 + 联赛·轮次·日期 + 关键数据。
2. **数据面板**：足球图型（按数据形状挑选）。
3. **战术拆解**：把比赛怎么打出来讲清楚（高效开局 / 被逆转 / 关键时段）。
4. **关键/机会**：关键人 / 良机→进球转化。

## 视觉（tiny type 蓝线稿）
- **纸灰底** `#FBFBFD` + **点阵网格** + **蓝发丝线** `#3E72E0` + **小字距大写标签**（`XX · TINY TYPE`）+ Inter。
- **强调色 = 赢家主色**：谁的比赛谁定色，**赢家用主色**（曼城胜→天蓝、贝蒂斯胜→绿、摩纳哥胜→红…）；对手用灰/浅色。**一图一套色**，不混搭。
- 图表**自然大小、居中、不拉伸**（`preserveAspectRatio="xMidYMid meet"` + `chartbox{flex:1}`），卡底底栏到底，既不满幅拉伸也不空。
- 小夜鹰 = **底部品牌栏小印记**（40px，不突兀）。
- 标题**语义换行**（不截断词）；比分完整、谁是谁清楚。

## 足球图型映射（按数据形状选）
| 足球数据 | 图型 |
|---------|------|
| 控球/占比 | Hundred Field / Dot Waffle（100 格，一格=1 单位） |
| 射门→射正→进球 | Rung Waterfall（逐级记数） |
| 球员节点/传球 | Pass Map（节点+连线） |
| 机会→进球转化 | 单位图（每格=1良机，绿色=转化） |
| 球员属性 | 雷达（5 维归一） |
| 比分进程+事件 | 时间轴（比分+关键事件，事件挤时换行/分栏） |
| 两队指标对比 | 雷达 / 分组对比（避免拥挤的横向条） |

## 数据规则（先核验再画）
- **先 `web_search` 核验**：比分、进球者+分钟、射门/射正/xG/控球、关键事件（失点/中柱/被吹/被挡）。多来源对照，引用来源。
- **真实数据**：比分/进球者/时间必须真实；传球、xG 等用官方统计。
- 拿不到逐球坐标/分钟时，**图表用示意并标注**（"坐标为示意""分钟为示意""点量为准"），不要当成真实数据误导。
- **中立**：双方都到、不偏一队；"碾压却输"要客观讲，不站队。
