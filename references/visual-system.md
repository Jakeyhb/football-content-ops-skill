# 视觉系统

一套让主页统一、硬朗、不翻车的信息图视觉。

## 1. 硬朗足球数据风（信息卡）
- 中性网格底 + **近黑深蓝字**（`#0E1A26`）+ 加粗黑体（PingFang SC / Noto Sans SC Heavy）。
- 干净、男向、不花哨；不做可爱/粉色。
- 基础样式：`assets/football-data.css`。
- **大字号**（比默认大）：标题 ~112px、小标题 ~50px、正文 ~44px、标签 ~36px、编号 ~34px。

## 2. 按队换色
同一布局，**只改 3 个 CSS 变量**：
| 变量 | 默认 | 说明 |
|------|------|------|
| `--blue` | 主色 | 编号/标签/主强调 |
| `--green` | 次色 | 副标/提示/下划线 |
| `--ink` | 文字 | 近黑 |

做法：`cp assets/football-data.css assets/themes/<team>.css` → 改 3 变量。

| 队 | `--blue` | `--green` |
|----|---------|-----------|
| 多特蒙德 | `#FDE100`(黄) | `#0A0A0A`(黑) |
| 曼城 | `#6CABDD`(天蓝) | `#E8C36A`(金) |
| 阿森纳 | `#D0021B`(红) | `#F1C40F`(金) |
| 国米 | `#0E4FA0`(蓝) | `#7FB6E8`(浅蓝) |
| 贝蒂斯/皇马 | `#1B2A4A`(深蓝) | `#C9A227`(金) |
| 沙尔克 | `#085CA8`(蓝) | `#9BC7EC`(浅蓝) |

已备：`assets/themes/{bvb,mancity,arsenal,inter,betis,schalke}.css`。

## 3. 固定 IP 小夜鹰（`assets/ip/night-owl.svg` / `-transparent.png`）
- 一只抱足球的夜鹰观察员，配色夜蓝/电蓝/暖橙。
- **固定身份，不断换场景**：抱球 / 哨子 / 球场 / 战术板 / 奖杯 / 数据 / 庆祝。
- 作为**每页右下角固定角标**（透明底，150px，`position:absolute; right:56px; bottom:100px`）。
- 封面角落也放一个。角色用账号色；场景/球队用主题色。

## 4. 封面规范
- **球场/球员实拍铺满** + 大字（白 + 主题色高亮词）→ 海报风。
- 左侧压暗（`linear-gradient`）保证文字可读。
- 顶部：`COMPETITION · 联赛 · 第N轮 · 日期`（如 `LA LIGA · 西甲 · 第4轮 · 09.05`）。
- 副标一行 + 蓝→金渐变小条。
- **不要**红蓝分屏 + VS 圆章（丑）。
- 有球员图用球员（单人/双人）；没有就用球场实景。

## 5. 排版规则
- **标题/封面主标题必须在语义处换行（用 `<br>`），绝不截断词/语意**——"安东尼"不要变成"安东/尼"，"瓦伦西亚"不要变成"瓦伦/西亚"，"伊普斯维奇"不要拆开。宁可主动加 `<br>`（如 `主队 vs<br>客队`），也不要让浏览器在词中间断行。
- 文字位置每张可变化（左上/左下/右侧/左侧），别每张都同一处。
- **卡内不写比分/数据**（易错、难改）——只写定性词。数据错了改文案、不动图。
